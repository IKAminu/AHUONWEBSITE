4.2 5-Day Resolution Clock (Integrity Platform Integration)
Business Logic:

Timeframe	Action	Auto-notification
Day 0 (Hour 0)	Complaint filed. EXCO notified.	EXCO email + SMS
Day 0-2 (48 hours)	EXCO reviews, assigns "valid" or "invalid". If valid, member notified.	Member email: "You have 5 days to resolve complaint #XXXX"
Day 2-5	Member responds via dashboard, proposes resolution. Pilgrim accepts/rejects.	Daily reminder emails to member if no response
Day 5 (End of day)	If unresolved: EXCO reviews. If EXCO decides fraud → Case packet exported to JSON. Sent to Integrity Platform API.	Pilgrim email: "Your case has been escalated to EFCC/Multi-Door Court. Reference number: [EFCC-XXXX]"
Day 5+	Integrity Platform handles further escalation. AHUON dashboard shows "Escalated".	-
API Integration Requirements (for Integrity Platform):

Endpoint to receive case: POST /api/v1/cases

Authentication: API key (provided by your platform)

4.3 Payment & Renewal Automation
Registration Payment Flow:

text
Applicant submits form → Redirect to Paystack → Payment successful → Webhook received by WordPress → 
→ Create user (pending_member) → Store meta data → Send email to EXCO
Renewal Payment Flow:

text
Member logs in → Clicks "Renew Now" → Paystack popup (fee pre-set) → Webhook received → 
→ Update membership_expiry_date (add 12 months) → Regenerate certificate → Send email to member with new certificate
Paystack Webhook Endpoint: https://ahuon.org.ng/wp-json/pmpro/v1/webhook

Automated Reminders (Cron Jobs):

Days Before Expiry	Action
60 days	Send email: "Your membership expires in 60 days. Renew now to avoid lapsed status."
30 days	Send email + (optional) SMS: "Your membership expires in 30 days. Renew now."
7 days	Send email + SMS: "Your membership expires in 7 days. RENEW NOW or you will be removed from public directory."
0 days (expiry day)	Change user role from member to lapsed_member. Remove from public directory. Send notification.
30 days after expiry (grace period)	Send final email: "Your membership has lapsed. You have been removed from the directory. To reinstate, pay renewal fee + late fee."
90 days after expiry	Delete user account (or archive). Notify EXCO.
PART 5: USER ROLES & PERMISSIONS
Role	Capabilities
Administrator (Developer/Your Agency)	Full access to all WordPress settings, plugins, themes. Can add/remove EXCO users. Initially you, then transfer to AHUON after launch.
ahuon_exco (President, Secretary, PRO, etc.)	Access EXCO dashboard. Can approve members, manage complaints, send notifications, view financial reports, generate certificates. Cannot change plugin settings or themes.
member (Approved, paid-up)	Access member dashboard. Can edit profile, renew, download certificate, view complaints against them, respond to complaints.
pending_member (Registered, not yet approved)	Cannot access directory or dashboard. Can only see "Your application is under review" page.
lapsed_member (Expired more than 30 days)	Cannot access directory. Can access limited dashboard showing "Your membership has lapsed. Pay now to restore."
subscriber (Public – pilgrims)	Can file complaints, check status, view directory, rate operators (after verified booking).
